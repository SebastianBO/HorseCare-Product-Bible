# Locked Tab Bar – Non-Negotiable

Every single screen (except pure onboarding, full-screen paywall, or modals) must use this exact bottom navigation.

## Spec
- 5 tabs + elevated center FAB
- Order & labels (exact, never change):
  1. Home
  2. Progress
  3. Community
  4. Marketplace
  5. Profile
- Icons: house, chart.bar, person.3, storefront / bag, person (SF Symbols style)
- Active: filled deep green #0A7A4B icon + bold green label
- Inactive: gray #8E8E93 outline + gray label
- Elevated circular green FAB (white + or camera) centered above the bar, slight shadow
- Identical height (~49pt + home indicator), icon size (~24-25pt), label size (10-11pt SF Pro), padding, safe area on EVERY screen
- Only the active highlight changes
