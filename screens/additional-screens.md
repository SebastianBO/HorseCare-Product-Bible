# Additional Screens – Detailed Specs & Image Prompts

## Horse Profile / Deep Timeline

**Layout:**
- Header: Back arrow | Horse name + small avatar | Share / Edit icons
- Hero section: Large recent photo or Health Index ring + key metrics (Weight, BCS, Last Scan, Hoof)
- Segmented control: Timeline | Overview | Documents | Photos | Team | Goals
- Timeline (default): Vertical feed of events with icons (camera for scans, hammer for farrier, syringe for vet, note), date, short summary, confidence if AI, expandable photo/details. Filter chips top.
- Sticky bottom or FAB context: New Scan / Add Note
- Perfect tab bar with Profile or Home active.

**Usability:** Everything about one horse in one place. Progressive disclosure. Searchable timeline.

## Care Calendar

**Layout:**
- Header: Calendar title | Month/Week/List toggle
- Calendar grid with color dots (green = scan, blue = vet, orange = farrier, purple = vax)
- Selected day detail or upcoming list of cards: Event type, date/time, "Mark Complete", "Reschedule", "Find Pro"
- Smart AI suggestion card: "Recheck recommended based on last BCS trend"
- Add Event big green button
